 # 3. Hafta – Uygulama Geliştirme, Git Kullanımı ve Docker Entegrasyonu

## Yapılan Çalışmalar

Bu hafta, önceki haftalarda edinilen teorik bilgilerin uygulamaya aktarılması ve yazılım geliştirme sürecine versiyon kontrol sistemlerinin entegre edilmesi üzerine çalışmalar gerçekleştirilmiştir.

Bu kapsamda, **Docker** altyapısı üzerinde çalışan PHP tabanlı bir başlangıç projesi oluşturulmuştur. Geliştirme ortamı Docker konteynerleri içerisinde yapılandırılmış ve `index.php` dosyası üzerinden temel uygulama yapısı hazırlanmıştır. Böylece PHP servislerinin konteyner tabanlı ortamlarda çalışması uygulamalı olarak test edilmiştir.

Oluşturulan proje, **Visual Studio Code** terminali kullanılarak **Git** versiyon kontrol sistemi ile yönetilmiştir. Proje klasörü içerisinde Git deposu başlatılmış, dosyalar sırasıyla `init`, `add`, `commit` ve `push` komutları kullanılarak GitHub ortamına aktarılmıştır. Bu süreçte, commit mesajlarının anlamlı ve düzenli olmasına dikkat edilerek profesyonel bir sürüm kontrol yapısı oluşturulmuştur.

Ayrıca, proje geliştirme sürecinde karşılaşılan hata ve sorunlar ekip içi iletişim amacıyla **Discord** platformu üzerinden değerlendirilmiş ve çözüm yolları tartışılmıştır. Bu sayede ekip içi iletişim ve teknik problem çözme becerileri geliştirilmiştir.

Versiyon kontrolü kapsamında **main branch** yapısı kullanılmış, proje dosya hiyerarşisi ve commit standartları uygulanarak düzenli ve sürdürülebilir bir depo yapısı oluşturulmuştur.

## Öğrenilen Bilgiler

- Docker ortamında PHP tabanlı uygulama geliştirme  
- Git komutları ile terminal üzerinden versiyon kontrolü  
- GitHub üzerinde proje yönetimi ve depo yapısı  
- Commit mesajı standartlarının önemi  
- Ekip içi teknik iletişim ve problem çözme süreci  

## Kullanılan Teknolojiler ve Araçlar

- Docker  
- PHP  
- Visual Studio Code (VS Code)  
- Git  
- GitHub  
- Discord
